## 1. 이 기능이 답하는 질문

**"내 집을 팔면 얼마짜리 집을 살 수 있는가"**

당산센트럴아이파크를 팔아 반포 인근으로 이주할 수 있는지를 본다.
매도 대금에서 양도세·중개보수·대출 상환을 빼고, 현행 대출 규제 아래에서
살 수 있는 주택 가격의 상한을 낸 뒤, 목표 지역(반포·잠원) 시세와 비교한다.

## 3. 계산 구조에서 주의할 점

### 대출 한도가 계단식이라 단순 역산이 안 된다

매수가가 대출 구간을 정하고, 구간이 대출 한도를 정하고, 한도가 다시 매수
가능가를 정한다. `가용자금 ÷ (1 + 부대비용률)` 한 번으로 풀면 틀린 답이 나온다.
구간마다 후보가를 만들고 유효성을 따로 검사해야 한다(`purchase_capacity.compute_capacity`).

### 25.0억 경계에서 대출이 4억 → 2억으로 떨어진다

```
        매수가          대출     필요자금   가능
 2,490,000,000원      4.00억   25.91억   가능
 2,499,999,999원      4.00억   26.02억   가능
 2,500,000,000원      2.00억   26.02억   불가   <- 여기서 계단
 2,510,000,000원      2.00억   26.12억   불가
```

억 단위로 반올림하면 두 행이 모두 "25.00억"이 되어 경계가 보이지 않는다.
그래서 구간별 판정표는 **원 단위**로 표시한다.

### 구간 정의는 [하한, 상한)

`min` 은 포함, `max` 는 미포함이다. 따라서 **정확히 25.0억은 세 번째 구간**이다.
개발요청서 §8 케이스 4의 최초 문구("25.0억은 가능")는 이 정의와 어긋나 정정했다.

### 양도차익 안분에 조합원 분양가를 쓰지 않는다

재건축 신축주택의 취득가액은 `종전주택 취득가액 + 실제 납부한 청산금`이다.
인가후 취득원가도 `권리가액 + 청산금`이며 조합원 분양가가 아니다.
분양가를 쓰면 안분 합계가 취득가액 기준 총액과 어긋나 경로에 따라 답이 갈린다.
계산 직후 항등식을 검사해 1원이라도 벌어지면 실패시킨다.

```
기존건물분 + 청산금분 == 매도가 - (종전주택 취득가액 + 부담금) - 필요경비
```

## 4. 미확정 항목 (개발요청서 §12)

| 항목 | 상태 | 처리 |
| :-- | :-- | :-- |
| 주담대 잔액 90,000,000 | **확정** (2026-09-07) | 그대로 사용 |
| 매수 부대비용률 4.07% / 4.27% | **적용** (2026-09-07) | 계산 반영, 결과에 금액 표시 |
| 매도 예상가 | **출처 확인됨** (2026-09-07) | 25.50억 네이버 호가 중간값(실거래 아님) / 24.35억 최근 3개월 실거래 중위(84㎡ A~D 합산). 병행 계산 |
| 대출 한도 구간 판정 기준 (실거래가 / KB시세 / 감정가) | **미확인** | 입력만 받고 계산에 쓰지 않는다. 화면에 선택 기준만 표시 |
| 재건축 조합원 장특공 기산 규칙 | **세무 확인 대기** | 공제율을 직접 입력받는다. 상한(개별 0.40 / 합계 0.80)은 적용 중이며 위반 시 계산을 중단한다 |
| 취득세 중과 (일시적 2주택 등) | **미확정** | 범위 밖. 확정되면 부대비용률이 달라진다 |
| 조합원 분양가 493,358원 차이 | **실제 납부액 확인 중** | 계산 경로에서 제외되어 **세액 영향 없음**. 화면에 경고만 표시 |

확인이 끝나면 바뀌는 곳
- 장특공 상한 → `config/tax_and_loan.yaml` 의 `long_term_deduction`
- 세율·대출 한도 → 같은 파일. 시행일과 출처를 함께 갱신한다
- 조합원 분양가 493,358원이 실제 납부액이면 → `부담금` 입력값에 반영

## 5. 재개할 때

화면에서 **매수 여력** 탭을 연다. 입력값은 브라우저에 저장되어 있어 다시 넣지
않아도 된다(개인 자금 정보라 저장소나 서버에는 남기지 않는다).

**현재 기준값**

```
매도 예상가        2,550,000,000  (호가. 실거래 2,435,000,000 과 병행 표시)
종전주택 취득가액     343,500,000
권리가액            431,139,690
부담금              271,916,952
조합원 분양가         703,550,000  (대조용. 계산에 쓰지 않음)
필요경비                      0
주담대 잔액          90,000,000
장특공 (기존건물분)   보유 0.40 / 거주 0.20
장특공 (청산금분)     보유 0.40 / 거주 0.08
보유 현금            70,000,000
추가 여유자금                 0
전용면적             85㎡ 이하
```

값이 바뀌면 결과·민감도표·결론이 즉시 다시 계산된다.

**숫자만 다시 확인하고 싶을 때**

```bash
python -m pytest tests/test_capital_gains.py tests/test_purchase_capacity.py -q
```

개발요청서 §8 케이스 1~6 이 그대로 고정되어 있다. 값이 바뀌면 실패한다.
허용 오차는 양도세 ±1만원, 매수 상한 ±500만원, 안분 항등식 0원이다.
