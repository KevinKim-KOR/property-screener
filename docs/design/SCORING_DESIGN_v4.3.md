## 1. 개요 및 배경
v4.3에서는 단순히 "얼마나 빠졌나(가격 하락률)"만 보여주던 대시보드 구조에서 탈피하여, **하락의 질(좋은 하락 vs 나쁜 하락)**을 판별할 수 있는 **입지·임차수요 지표 5종**을 대폭 도입했습니다. 또한 지표 확장에 따라 컬럼이 17~18개로 늘어남에 따라, 사용자 관점에서 필수 정보에 집중할 수 있도록 **UI 컬럼 고정 및 프리셋 시스템**을 개편했습니다.

## 2. v4.3 핵심 개편 항목

### ① UI 컬럼 고정, 평형 표기 개편 및 그룹 프리셋
* **고정 컬럼 (`지역 | 단지명 | 평형`)**:
  * 브라우저 가로 스크롤 시에도 왼쪽에 고정되도록 CSS/JS 구조를 개편했습니다.
  * 고정 컬럼 폭 최적화: `지역(100px) | 단지명(220px, 말줄임 처리) | 평형(130px)`
* **평형 표기 개편**:
  * 기존 `34평형 · 전용 84㎡`에서 **`34평 / 84㎡`**로 직관적이고 간결하게 개선했습니다.
* **그룹 프리셋 버튼 (4개)**:
  * `가격 (기본)`: 최근 거래가 · 전고점 · 전고점 시점 · 하락률 · 초과하락 · 전세가율
  * `흐름`: M3 · M6 · M12 · 거래 건수 · 거래량비
  * `단지`: 연식 · 브랜드 · 역세권 · 학원가 · 학교거리
  * `전체`: 모든 선택 가능 컬럼 표시
  * 개별 컬럼 체크박스 지원 및 브라우저 `localStorage('screener_visible_cols')`에 선택 상태 유지.

### ② 전세가율 (`jeonse_ratio`) 공식화 및 파서 견고성 강화
* **공식**:  
  $$\text{전세가율} = \frac{\text{최근 6개월 전세 보증금 중위 (만원)}}{\text{최근 매매 실거래가 (만원)}} \times 100$$
* **정제 조건**:
  * **순수 전세 계약만 산출**: 월세금이 0원인 계약만 포함(반전세 및 월세 거래 제외).
  * **매칭 기준**: 동일 단지 · 전용면적 5㎡ 버킷 매칭. 최소 2건 이상 실거래 존재 시 산출하며, 미달 시 빈칸 처리.
* **CSV 적재 로직 개선 (`oci/crawler/molit_schema.py`)**:
  * 국토부 전월세 CSV의 실제 헤더인 **`월세금(만원)`**을 정확히 파싱하도록 매핑 수정.
  * 필수 컬럼 누락 시 조용히 0으로 채우지 않고 예외(`KeyError`)를 발생시켜 데이터 누락 및 오염을 근본 차단.

### ③ 단지 좌표 (`lat`, `lng`) 카카오 로컬 API 지오코딩
* **실행 모듈**: `pc/features/geocode_complexes.py`
* **방식**:
  1. `시군구명 + 본번-부번` 지번 주소로 1차 카카오 로컬 API(`dapi.kakao.com/v2/local/search/address.json`) 변환 시도.
  2. 실패 시 `도로명 주소`로 2차 시도.
  3. 실패 시 목록으로 출력 및 유지 (임의 값 기입 금지).
* **결과**: 유효 단지 1,449곳 중 1,444곳 좌표 확보 완료 (5곳은 재건축에 따른 지번 소멸/변경 단지로 정상 확인).

### ④ 역세권 거리 (`subway_str`)
* **실행 모듈**: `pc/features/update_subway_dist.py`
* **방식**: 카카오 로컬 API 카테고리 검색(`SW8` - 지하철역)으로 각 단지 기준 최근접 지하철역과 직선거리(m) 조회.
* **표기 형식**: `강남역 320m`, `사당역 47m` (1.5km 초과 시 빈칸 표시).
* **결과**: 1,444곳 중 1,431곳(99.1%) 역세권 정보 반영 완료.

### ⑤ 학원가 밀도 (`academies_str`)
* **실행 모듈**: `pc/features/update_academies_count.py`
* **방식**:
  * 카카오 로컬 API 카테고리 검색(`AC5` - 학원)으로 단지 반경 1km 내 학원 수 조회.
  * **페이징 상한(45건) 극복**: 단지 주변 학원이 수백~수천 개에 달하는 대치동 특성을 반영하여, 목록 개수가 아닌 API 응답의 **`res.meta.total_count`** 값을 사용하여 정확한 총합 기록.
* **표기 형식**: `학원 87곳`, `학원 1692곳` (단지 프리셋 표시).
* **결과**: 1,444곳(100%) 반영 완료. 대치동 핵심 단지(1,639~1,692곳) 최상단 및 외곽 단지 하위권 분포 검증 완료.

### ⑥ 초·중학교 거리 (`schools_str`)
* **실행 모듈**: `pc/features/update_schools_dist.py`
* **방식**:
  * 카카오 로컬 API 카테고리 검색(`SC4` - 학교, 반경 2km 이내, 거리순 정렬, 최대 3페이지 조회).
  * **정밀 필터링 적용**: `SC4`에 섞여 들어오는 고등학교·대학교·병설유치원·어린이집·버스정류장 등을 모두 배제하고, 이름이 `~초등학교`, `~중학교`(`~여자중학교` 등 포함)로 확인되는 학교의 최근접 직선거리를 각각 추출.
* **표기 형식**: `초 180m / 중 420m` (2km 초과 항목 빈칸 처리).
* **결과**: 1,444곳(100%) 정보 산출 완료. 300m 이내 초근접("초품아") 단지 380곳(26.3%) 확인.
